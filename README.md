# Venkatasaianand Dark Theme

A deep, low-glare dark theme for Visual Studio Code with vivid, easy-to-read syntax colors.

## Install

1. Open the **Extensions** view (`Ctrl+Shift+X` / `Cmd+Shift+X`).
2. Search for **Venkatasaianand Dark Theme** and click **Install**.
3. Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`), run **Preferences: Color Theme**, and pick **Venkatasaianand Dark**.

## Recommended settings (optional)

The theme was designed alongside these fonts. Install them separately, then add the following to your `settings.json`:

- [Monaspace](https://github.com/githubnext/monaspace) (free) for the terminal
- [Comic Code](https://tosche.net/fonts/comic-code) (commercial) for the editor, or any ligature font you like

```jsonc
"editor.fontFamily": "'Comic Code Ligatures Light', Consolas, 'Courier New', monospace",
"editor.fontLigatures": true,
"terminal.integrated.fontFamily": "'Monaspace Radon Light', monospace",
"terminal.integrated.fontSize": 16.5,
"terminal.integrated.cursorStyle": "line",
"terminal.integrated.cursorBlinking": true,
"terminal.integrated.cursorWidth": 2
```
